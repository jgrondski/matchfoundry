Batch-specific notes

  • OBSHubPage.tsx: obs-cards-grid → guide §8 classes.
  • ObsOverlayPage.tsx renders OBS overlays with fixed positioning and chroma backgrounds. Chroma colors come from the URL, so they are runtime: keep them inline.
  • PublicTierBracketPage.tsx: the contentStyle objects passed to the layouts include a runtime background: tierBg plus static conditionals on localViewMode. Keep that prop interface (it is consumed by the layouts in A1); only convert elements this file renders itself.
  • TournamentSwitcherPage.tsx: the tournament grid repeat(auto-fill, minmax(480px, 1fr)) → grid-cols-[repeat(auto-fill,minmax(480px,1fr))]. Don't fix the mobile overflow here; that's Phase 12.
  • ManageTournamentPlayersPage.tsx contains hover handlers (guide §7).
  • Overlays in ManageTournamentPlayersPage, ManageTournamentSettingsPage and TournamentSwitcherPage were replaced in 11.1. Don't touch their props.

Style-coupled tests

None. No test in this batch's area asserts on rendered inline styles. Every test must pass unchanged.

Procedure

  1. Confirm the branch (index rule 1) and that git status --short shows no changes to files in this batch.
  2. Convert one file at a time with the guide's per-file procedure (§2). After each file, run npm run lint:styles -- <that file> until it shows 0 errors, then run npm run typecheck.
  3. After every 3 files, and at the end, run npx vitest run src/routes.
  4. Update the style-coupled tests, if any, as described above.

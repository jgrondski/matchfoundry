Batch-specific notes

  • TournamentSidebar.tsx (≈82 sites) is the largest file. Collapsed and expanded widths (60px/220px) are static conditionals: use cn(isCollapsed ? 'w-15 min-w-15' : 'w-55 min-w-55'). Keep the width transition as transition-[width,min-width] duration-200.
  • SpectatorLayout.tsx: delete both className="hidden-mobile" attributes (the class was never defined). Convert the nav pills to <Chip> without an accent. The contentStyle prop stays a runtime pass-through.
  • TopNavSwitcher.tsx: the grid uses a runtime column count (navTabs.length), so keep gridTemplateColumns inline. top-nav-teleport-chip → max-[860px]:hidden (guide §8).
  • App.tsx: the config-error screen uses fontFamily: 'Inter, …' → font-sans; the #e6edf3/#58a6ff code colors → text-fg / text-[#58a6ff] (report the latter).
  • ErrorBoundary.tsx is a class component; convert its JSX the same way.
  • TournamentLayout.tsx: the contentStyle prop is a runtime pass-through; keep style={{ ...contentStyle }} merged after the classes.

Batch-specific notes

  • The overlay shells of MatchScoreDrawer, MatchTelemetryModal and ShareBracketModal were done in 11.1. Convert only their interiors, and keep panelStyle runtime values as they are.
  • MatchCardFeed.tsx: card backgrounds use getAlternateShade(cardColor, n) keyed on hover state. These are runtime, so keep them inline. Preserve data-testid="feed-match-card".
  • SheetMatchRow.tsx has 8 hover handlers. organizerSheetMatrix.test.ts asserts that the hover tint helper returns an rgba string, so keep the helper. Apply the tint with style={{ '--row-hover': hoverTint }} and hover:bg-(--row-hover).
  • The spinner in MatchScoreDrawer (animation: 'spin 0.8s linear infinite') → animate-spin. It starts actually spinning (previously the keyframe was undefined), which is accepted.
  • ObsMatchCardView.tsx and ObsBracketView.tsx render inside OBS with chroma-key colors from the URL. Those colors are runtime.

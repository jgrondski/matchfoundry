Batch-specific notes

  • PlayerDetailDrawer.tsx (≈128 sites) is the largest file. Its overlay shell and panelStyle were done in 11.1.
  • LeaderboardTable.tsx uses shared thStyle/tdStyle objects. Replace them with const thClass = … / const tdClass = … strings, combined with cn() where a cell adds minWidth or textAlign. Preserve data-testid="open-qualifier-entry".
  • QualifierEntryModal.tsx: keep panelTestId="qualifier-entry-modal".
  • TournamentQualTimerHud.tsx has 26 hex values for timer states (green, amber, red). Map them with guide §5b; status choices are static conditionals, so use cn().

Step 12.1c: Landing page, global top nav and page header

The landing page and the global top nav (also used by the player directory and organizations pages) fit a phone, and the shared page header used by the leaderboard and standings wraps cleanly.

Wave 1. Runs in parallel with 12.0a, 12.0b and 12.1a. Uses nothing from 12.0a or 12.0b. Read first: index.html rules and Phase 12 conventions.

Files (only these)

ActionPath
Modifysrc/components/TopNavSwitcher.tsx, src/routes/TournamentSwitcherPage.tsx, src/features/tournament/components/TournamentCard.tsx, src/components/TournamentPageHeader.tsx

A. TopNavSwitcher.tsx

  • On mobile the header wraps into two rows: give the header row max-md:flex-wrap max-md:gap-y-2 max-md:px-3 max-md:py-2.
  • Row 1 holds the logo (scaled down with max-md:text-base) and the right-side actions as icon-only buttons: each action's text label gets max-md:sr-only, and each action gets an aria-label equal to its visible desktop label.
  • Row 2 is the tab grid at full width: max-md:order-last max-md:w-full max-md:max-w-none. Tabs get max-md:min-h-11 max-md:text-xs.
  • The teleport chip is already hidden at 860px and below; leave it.
  • Keep the MATCH + FOUNDRY + ™ markup intact (src/components/__tests__/rebrand.test.tsx asserts on it).

B. TournamentSwitcherPage.tsx (landing, /)

  • Every tournament grid using grid-cols-[repeat(auto-fill,minmax(480px,1fr))] becomes grid-cols-1 md:grid-cols-[repeat(auto-fill,minmax(480px,1fr))].
  • Page padding on mobile: max-md:px-4. Hero and title sizes drop one step on mobile (each text-Nxl gets the next smaller size as max-md:, for example text-3xl gets max-md:text-2xl).
  • Action buttons (create tournament, show test tournaments and similar) stack full width: their row gets max-md:flex-col max-md:items-stretch and each button max-md:w-full.
  • Keep the legal footer line unchanged.

C. TournamentCard.tsx

At a content width of 328px (360 minus two 16px gutters), nothing may overflow. Every horizontal row of stats, pills or buttons gets flex-wrap; the tournament name and organization name get min-w-0 and truncate (single line) or break-words (where the desktop design already wraps). The whole card stays one tap target, as today. Tier pill links keep working.

D. TournamentPageHeader.tsx

Used by the leaderboard and standings pages. On mobile: the title row gets max-md:flex-wrap; the action slot moves below the title at full width (max-md:w-full); the search input is max-md:w-full max-md:text-base; the title drops one size step.

Step 12.5c: Organizer sheet

The organizer sheet (/:slug/manage/sheet) stays a dense matrix and scrolls inside its own container on phones.

Wave 2. Needs wave 1’s gate. Runs in parallel with every other wave 2 step. Read first: index.html rules and Phase 12 conventions (the “Forms” bullet applies to every form here).

Files (only these)

ActionPath
Modifysrc/routes/ManageSheetPage.tsx, src/features/bracket/components/OrganizerSheetMatrix.tsx, src/features/bracket/components/sheet/SheetMatchRow.tsx, src/features/bracket/components/sheet/SheetTelemetryBar.tsx

Changes

  • The matrix's table or grid sits inside an overflow-x-auto overscroll-x-contain wrapper (if it isn't already). The page itself must not overflow.
  • The match/player identity column is sticky: its cells get sticky left-0 z-10 plus the row's background (the same background class or runtime color the row uses, so content doesn't show through).
  • SheetTelemetryBar: its row gets flex-wrap; stat items get min-w-0.
  • Any sticky header in ManageSheetPage at top-0 gets max-md:top-12. Page padding follows the conventions.

Verification

  • npm run typecheck passes for your files.
  • npx vitest run src/features/bracket passes with no edits to existing tests.
  • npx playwright test --project=mobile-overflow --grep "\[12.5c\]" passes, or fails only on elements in other steps' files (report them).

Manual check at 360×800 (gate)

  • Tap a match row; the score sheet opens.

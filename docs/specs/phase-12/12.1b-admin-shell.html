Step 12.1b: Admin shell

On phones the admin sidebar rail is replaced by a slim top bar (which tournament, and a link to its public view) and a bottom bar with four shortcuts and a Menu button that slides the full sidebar up as a sheet.

Wave 2. Needs wave 1's gate. Runs in parallel with every other wave 2 step. Every admin page's overflow result depends on this step. Read first: index.html rules and Phase 12 conventions (especially “Admin bottom bar clearance”).

  • Tapping Menu slides a bottom sheet up from just above the bar, holding the full sidebar (tournament switcher, Lock/Unlock, Public View, every section, system pages, Log Out). The Menu icon becomes ✕ and stays tappable; tapping it again collapses the sheet. Choosing an item, tapping the dimmed area, or pressing Back also closes it.
  • The four shortcuts always navigate (and close the sheet if it is open). Every navigation from the bar or the sheet goes through the layout's onNavigate guard, so Settings with unsaved changes still shows the Discard prompt.
  • Score sheets and other overlays slide up over the bar (they sit above it); the bar is visible again when they close.

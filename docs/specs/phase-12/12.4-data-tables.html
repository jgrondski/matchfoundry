Step 12.4: Data tables become card lists

Final standings, the tournament roster and the global player directory render as card lists on phones. (The qualifiers leaderboard is done in 12.2.)

Executor: any model. Can run in parallel with 12.2 and 12.3. Prerequisite: 12.1 committed. Read first: index.html rules, 12.0's “Conventions”, and the conversion guide.

Pattern (applies to every table here)

  1. The card list takes the same row data the table already computes. If that computation is inline in the JSX, extract it into a function in the same file first, then use it for both.
  2. The parent renders the card list when useIsMobile() is true, and the table otherwise. Tests run with useIsMobile() === false, so table tests stay valid.
  3. The list is <ul className="flex flex-col gap-2">, with each item a Card padding="sm". If a table row is clickable, the whole card is one <button> doing the same thing. If a row has action buttons, they're IconButtons with plain-word aria-labels in the card's top-right corner.
  4. Values and formatting are copied from the table cells (the same helper calls), never reimplemented.
  5. Search, filter and sort controls above the table stack full width on mobile (max-md:flex-col max-md:items-stretch, with inputs max-md:w-full).

B. Tournament roster (src/routes/ManageTournamentPlayersPage.tsx)

Columns today: #, Competitor, Country, Playstyle, Personal Best, Actions. Card: line 1 is #, flag and name, with action IconButtons on the right (the same actions as the Actions cell); line 2 is the playstyle chip, then “PB” and the personal best (font-mono), plus the seed or tier assignment if the page shows it. The page's top action buttons (register, import, and so on) wrap and go full width on mobile.

C. Global player directory (src/features/players/components/PlayerDirectorySections.tsx, PlayerDirectory.tsx)

Columns today: #, Competitor, Country, Playstyle, Personal Best, Status, Notes, Actions. Card: line 1 is #, flag and name, and the actions; line 2 is the playstyle chip, PB, and the status badge; line 3, only when there are notes, is the notes text clamped to two lines (line-clamp-2 text-xs text-fg-secondary). Keep the header text of the desktop table identical (directorySections.test.tsx asserts on it).

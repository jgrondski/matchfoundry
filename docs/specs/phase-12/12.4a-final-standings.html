A. FinalStandingsCardList.tsx

  1. The card list takes the same filtered rows the table maps over. For each cell the card shows whose formatting is inline JSX (Qual & Delta, Stage Reached, Exit Match / Loss Avg, Match Rec, Game Rec, Game Score Avg), extract it into an exported function or small component in FinalStandingsTable.tsx and use it in both. The table renders identically.
  2. Props: rows (the table's row type), isObsMode: boolean, and onSelectPlayer with the same signature as the table's handlePlayerClick.
  3. FinalStandingsTable renders the card list in place of the table container when useIsMobile() is true. The page header and filter pills stay shared.

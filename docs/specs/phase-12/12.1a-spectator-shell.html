Step 12.1a: Spectator shell

Spectators reach every public page of a tournament from a bottom tab bar, the header fits on one 48px row, and the bracket tier bar stops stacking controls.

Wave 1. Runs in parallel with 12.0a, 12.0b and 12.1c. Uses nothing from 12.0a or 12.0b. Read first: index.html rules and Phase 12 conventions.

A. Spectator header (SpectatorLayout.tsx)

  1. Move the navItems array (currently built inline around line 60) into an exported function in the same file: export function getSpectatorNavItems(tournament: Tournament, activeTierSlug?: string), taking whatever other inputs the inline code uses as extra parameters. It returns the same objects in the same order. The header pills and the bottom nav both use it. Export the item type as SpectatorNavItem ({ id; label; icon: LucideIcon; to: string }, with id typed as the existing view-id union; if there is no named union, create export type SpectatorNavView from the ids in the array).
  2. Header on mobile: add max-md:h-12 max-md:px-3 max-md:gap-2 to the header row.
  3. The “All Tournaments” link shows only its arrow icon on mobile: wrap its label in <span className="max-md:sr-only"> and add aria-label="All tournaments" to the link.
  4. The tournament name block gets min-w-0 flex-1. Its name span gets truncate, and its fixed max-w-[220px] gets max-md:max-w-none beside it. Hide the organization line on mobile (max-md:hidden).
  5. The center <nav> holding the pills gets max-md:hidden.
  6. The Share button's label span gets max-md:sr-only. The Manage and Staff Login labels get max-md:sr-only, and their links get aria-label="Manage tournament" and aria-label="Staff login".
  7. Render <SpectatorBottomNav items={navItems} activeView={activeView} /> as the last child of the layout root, after the content wrapper (use the same active-view value the pills use). Give the content wrapper max-md:pb-[calc(3.5rem+env(safe-area-inset-bottom))].
  8. Leave any fit-mode height calc(100vh - 56px) alone; fit mode isn't offered on phones (section C).

  • Root on mobile: max-md:flex-col max-md:items-stretch max-md:gap-2 max-md:px-3 max-md:py-2 max-md:top-12 (it sits under the 48px spectator header on public pages and under the 48px admin top bar from 12.1b on manage pages).
  • Left group (tier chips): the sideways-scrolling chip row classes from the conventions. Hide the “Tier:” label and the “Add Tier” link on mobile (max-md:hidden). Chips get shrink-0.
  • Right group on mobile: max-md:justify-between max-md:flex-wrap.
    • Player search: max-md:hidden.

Its label stays “Mobile” on desktop and reads “List” on mobile: replace its <span>Mobile</span> with <span className="max-md:hidden">Mobile</span><span className="md:hidden">List</span>. 12.3 adds the Bracket chip later.

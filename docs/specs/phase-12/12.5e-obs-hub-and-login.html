Step 12.5e: OBS hub and admin login

The OBS hub (/:slug/obs), the admin login page (/admin) and the admin login modal fit a phone.

Wave 2. Needs wave 1’s gate. Runs in parallel with every other wave 2 step. Read first: index.html rules and Phase 12 conventions (the “Forms” bullet applies to every form here).

Files (only these)

ActionPath
Modifysrc/routes/OBSHubPage.tsx, src/routes/AdminLoginPage.tsx, src/features/auth/AdminLoginModal.tsx

A. OBSHubPage.tsx

  • The card grid is already one column below 681px; leave it.
  • Copy-URL rows: the URL text gets min-w-0 truncate; the row is flex items-center gap-2 with the URL as flex-1. The two “Copy URL” buttons (around lines 157 and 201) keep their label on desktop; on mobile the label span gets max-md:sr-only and the button gets max-md:size-11 max-md:justify-center max-md:p-0 and aria-label="Copy URL".
  • Page padding and title follow the conventions.

B. AdminLoginPage.tsx and AdminLoginModal.tsx

  • The login card is full width on mobile with max-md:px-4; the page container uses max-md:px-4.
  • The PIN inputs (around line 213 in the page, line 114 in the modal) get inputMode="numeric" and max-md:text-base. Keep their type unchanged.
  • The submit button is max-md:w-full.

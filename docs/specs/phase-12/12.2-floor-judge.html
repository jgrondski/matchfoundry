B. Qualifiers (public leaderboard and /manage/qualifiers)

LeaderboardCardList.tsx

This takes the same rows LeaderboardTable already computes. Extract the row-model computation into a function in LeaderboardTable.tsx if it's inline, and pass the result to both. LeaderboardTable renders <LeaderboardCardList> instead of <table> when useIsMobile() is true. Each row is an <li> card, and the whole card is a <button> that triggers the same row action the table row triggers (opening PlayerDetailDrawer).

Card lineContent (by qual format)
Line 1Rank (w-8 font-mono text-sm font-bold), flag and name (min-w-0 flex-1 truncate font-semibold), primary metric right-aligned (font-mono font-bold): AVERAGE_OF_X → average score; HIGH_SCORE → top score; POINTS → total points. Use the same values and formatting as the table cells.
Line 2Status badge (the same states as the Verified column), playstyle chip, bracket seed if the table shows it.
Line 3 (only when the table has the column)AVERAGE_OF_X: the top-score chips. HIGH_SCORE: maxes and kicker as “Maxes 3 · Kicker 812,340”. POINTS: the points breakdown in its existing compact form.

Tier dividers or cutoff lines that the table renders between rows render between cards as full-width labeled separators.

Record score action (admins): on mobile, the button with data-testid="open-qualifier-entry" moves into a bar at the bottom of the page, fixed inset-x-0 bottom-0 z-40 border-t border-line bg-surface p-3 pb-[calc(0.75rem+env(safe-area-inset-bottom))] md:static md:…, as a full-width primary Button. Keep a single element: don't duplicate it. The list gets bottom padding so the bar never covers the last card.

Entry and detail overlays

  • QualifierEntryModal (bottom sheet): the score input gets inputMode="numeric" and max-md:text-base. The submit/cancel footer is sticky bottom-0 with full-width buttons on mobile. The CreatablePlayerSelect dropdown list gets max-h-[40dvh] overflow-y-auto and full width, and its options are min-h-11.
  • PlayerDetailDrawer (bottom sheet): sections stack; any two-column stat grids become max-md:grid-cols-2 (not 3–4); its score input gets inputMode="numeric".
  • TournamentQualTimerHud: the compact variant fits in 328px; wrap rather than overflow.

ReviewQueueCardList.tsx

Same props as ReviewQueueTable (ReviewQueueTableProps). ReviewQueueTable renders it instead of the table when useIsMobile() is true. One card per session:

AreaContent (same data and formatting as the table cells)
HeaderCompetitor name and identity status badge (left); review status badge (right).

ActionsFull-width primary Button “Review” → onOpenAdjudicate(session). Then a row of secondary buttons: “VOD” (a link opening the VOD URL in a new tab, rel="noopener noreferrer", only when there is one), “Identity” → onOpenIdentityModal(session) (only when the table shows that action for the row), and “Discard” (danger, ghost-styled) → onDiscardRun(session) (only when the table shows it). Use the same conditions the table uses.

  • IdentityResolutionModal (bottom sheet): tabs scroll sideways; the search input and result list are full width; result rows are min-h-11.

Step 12.1: Navigation shell

Spectators can reach every public page from the landing page on a phone, and admins can reach every manage page through a menu. This step fixes the stacked-controls problem on the bracket page.

Executor: any model. Runs alone. Prerequisite: 12.0 committed. Read first: index.html rules, 12.0's “Conventions”, and the conversion guide.

  2. The root gets max-md:flex-col.
  3. On desktop (!isMobile), render TournamentSidebar exactly as today.
  4. On mobile, render <AdminMobileTopBar title={tournament?.name ??

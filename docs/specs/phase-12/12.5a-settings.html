Changes

  • Apply the conventions' “Forms” rules to every form section in the listed files. This includes the event date pickers in TournamentInfoSection.tsx (each max-md:w-full max-md:text-base).
  • The “Save Configuration” bar (TournamentAdminForm.tsx, around line 872, already sticky bottom-4) gets max-md:bottom-[calc(3.5rem+env(safe-area-inset-bottom))] max-md:-mx-4 max-md:rounded-none max-md:px-4 max-md:flex-col max-md:items-stretch max-md:gap-2 so it sits directly above the admin bottom bar (see “Admin bottom bar clearance” in the conventions); its buttons get max-md:w-full.
  • TierManagementSection.tsx: each tier row stacks into a card on mobile (max-md:flex-col max-md:items-stretch); color swatches and pickers sit in a max-md:grid max-md:grid-cols-2 max-md:gap-2; per-tier action buttons wrap.
  • RoundOverridesEditor.tsx: the per-round grid sits in an overflow-x-auto wrapper (if it isn't already), and its first column is sticky (sticky left-0 z-10 bg-surface, or the row's background token if rows alternate).
  • BracketThemeEditor.tsx: the preview stacks below the controls on mobile (max-md:flex-col or max-md:grid-cols-1, whichever its layout uses).
  • Overlays opened from settings (PointsThresholdsDrawer, the modals in settings/AdminFormModals.tsx, SharedPinWarningModal): their footers use the conventions' sticky sheet footer classes with full-width buttons.
  • DataSimulationSection.tsx: its button groups wrap and go full width on mobile.

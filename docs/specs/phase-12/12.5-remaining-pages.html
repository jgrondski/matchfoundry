Step 12.5: Remaining pages and full-app sign-off

Everything not covered by 12.1–12.4, then the overflow test across every route. Phase 12 is done when this step passes.

Executor: any model; the sub-steps below can be split between sessions because their files don't overlap. Prerequisite: 12.2, 12.3 and 12.4 committed. Read first: index.html rules, 12.0's “Conventions”, and the conversion guide.

Out of scope

OBS overlay routes (/:slug/obs/bracket…, /:slug/obs/match/…, /obs/…, and any page with ?obs=true). These are fixed-size broadcast surfaces rendered by OBS, not phones. The OBS hub (/:slug/obs) is in scope.

General rules for this step

  • Multi-column form grids become one column on mobile (max-md:grid-cols-1). Side-by-side field rows stack (max-md:flex-col max-md:items-stretch).
  • Form inputs are max-md:w-full max-md:text-base (16px avoids iOS zoom).
  • Page containers use max-md:px-4 max-md:py-4. Page titles drop one size step on mobile.
  • Toolbars with several buttons wrap (flex-wrap). Primary page actions are full width on mobile.

12.5b: Seeding (/manage/seeding)

Files: src/features/tournament/components/seeding/* and the seeding route component.

  • Touch reordering: HTML5 drag and drop doesn't work with touch. On mobile (useIsMobile()):
    • Hide drag handles.
    • Show two IconButtons per row, “Move up” (ChevronUp) and “Move down” (ChevronDown), that call the same reorder function the drop handler calls, with (index, index - 1) and (index, index + 1). Disable them at the ends and when isLocked.
    • The existing “Jump to Seed” action stays available on each row.
  • The sticky toolbar wraps, and on mobile it sits below the admin top bar (max-md:top-12).
  • DualListSeedingModal (bottom sheet): the two lists become two tabs on mobile, “Available” and “Seeded (N)”, built with Chips. The move buttons (→ / ←) become full-width “Add to seeding” / “Remove” buttons under the active list.
  • BulkSeedImportModal: the textarea is full width with min-h-[40dvh], and the destination options stack.

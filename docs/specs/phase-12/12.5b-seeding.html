A. Touch reordering (ManualSeedingManager.tsx)

HTML5 drag and drop doesn't work with touch. The rows already have Move to top, Move up, Move down, Move to bottom and Remove buttons (around lines 745–790). On mobile:

  • Hide the drag handle (around line 650): add max-md:hidden to both the handle and its locked-state spacer.
  • The manage-mode row (around line 635) gets max-md:flex-wrap max-md:px-3. The controls container (w-37.5 shrink-0, around line 745) gets max-md:w-full max-md:justify-end so the controls drop to their own line.
  • rowControlClass (line 29) gets max-md:size-11 max-md:items-center max-md:justify-center.
  • “Jump to Seed” stays available.
  • The sticky toolbar (around line 422, sticky top-4) gets max-md:top-14 max-md:px-3 (below the 48px admin top bar plus a gap); its contents already wrap.

B. DualListSeedingModal.tsx

On mobile (useIsMobile()), the two lists become two tabs, “Available” and “Seeded (N)”, built with two Chips above a single list area; only the active list renders. The move buttons (→ / ←) are replaced under the active list by one full-width button: “Add to seeding” on the Available tab and “Remove” on the Seeded tab, calling the same handlers. Desktop is unchanged. Default tab: Available.

C. BulkSeedImportModal.tsx

The textarea is w-full max-md:min-h-[40dvh] max-md:text-base; the destination options stack (max-md:flex-col max-md:items-stretch); the footer uses the sticky sheet footer classes.

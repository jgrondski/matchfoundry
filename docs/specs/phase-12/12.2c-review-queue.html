Step 12.2c: Review queue

A judge works the qual review queue (/:slug/manage/review) from a phone: one card per qual, and the adjudication and identity sheets fit.

Wave 2. Needs wave 1's gate. Runs in parallel with every other wave 2 step. Read first: index.html rules and Phase 12 conventions, especially “Card lists”.

A. ReviewQueueCardList.tsx

  1. ReviewQueueTable keeps its filter pills and search box (they render in both layouts). Below them, it renders <ReviewQueueCardList> in place of the table container (the overflow-hidden rounded-md border div holding the <table>) when useIsMobile() is true, passing the already-filtered sessions.
  2. Props: 
    interface ReviewQueueCardListProps {
  sessions: ReviewQueueSessionSummary[];   // already filtered
  onOpenAdjudicate: (session: ReviewQueueSessionSummary) => void;
  onOpenIdentityModal: (session: ReviewQueueSessionSummary) => void;
  onDiscardRun?: (session: ReviewQueueSessionSummary) => void;
  qualWindowMinutes: number;
}
  3. For any cell whose content the card repeats and whose logic is inline JSX (identity badge, status badge, qual total time, abandoned flag, scores), extract it into an exported function or small component in ReviewQueueTable.tsx and use it in both. The table must render identically.
  4. When the list is empty, render the same empty-state text the table shows.

B. ReviewQueueView.tsx and ManageReviewPage.tsx

  • The filter pill row in ReviewQueueTable gets the sideways-scrolling chip row classes (replacing flex-wrap on mobile with max-md:flex-nowrap); each pill gets shrink-0. The search box wrapper gets max-md:w-full and its input max-md:text-base.
  • In ReviewQueueView, the “Verify All” button gets max-md:w-full; the header stats row gets flex-wrap.
  • In ManageReviewPage, the page container follows the conventions' page padding and title rules.

C. Sheets

  • AdjudicationModal.tsx: the VOD link is a full-width secondary button near the top on mobile (max-md:w-full; move nothing on desktop). Score inputs get inputMode="numeric" and max-md:text-base. The decision buttons (Save, Verify Qual / Save & Verify, Unverify, Mark DNQ, Disqualify) stack full width on mobile (max-md:flex-col max-md:items-stretch on their rows, max-md:w-full on each), keeping their current order. The judge notes textarea is w-full max-md:text-base.
  • IdentityResolutionModal.tsx: its tabs scroll sideways (chip row classes); the search input is max-md:w-full max-md:text-base; the result list is full width and its rows are min-h-11.

D. Tests

reviewQueueCardList.test.tsx (renderToStaticMarkup, with sessions built in the test following src/features/online-quals/__tests__/reviewWorkflow.test.tsx): every session renders its name and a Review button; Discard appears only for an IN_PROGRESS session when onDiscardRun is passed, and never when it is undefined; a VOD link renders with rel="noopener noreferrer" when the session has a VOD URL.

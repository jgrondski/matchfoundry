Step ER.7: Inline loading, global busy lock and error banner

Shared pieces that make every action behave the same way. The clicked button shows a spinner and loading text, every other button is disabled until the call finishes, and after 10 seconds the user gets an error banner and the button comes back. ER.8 converts the actual flows.

Executor: any model. Prerequisite: none. Can run in parallel with ER.2–ER.4. If ER.6 is also pending, run this step first (both edit App.tsx and store.tsx). This step is allowed to edit the frozen files it lists under src/components/ui and src/components/overlay. Read first: index.html “Rules for every executor”, docs/TESTING_STRATEGY.md, docs/UI_ARCHITECTURE.md.

Rules this step establishes

  • One action at a time. While any action started through useAction is running, every Button and IconButton in the app is disabled, except ones marked ignoreBusy (the banner's dismiss button). Chips, links and form inputs are not affected. Background refreshes (focus, live updates) never set busy.
  • The clicked button shows progress: a spinner plus loadingText (for example “Saving…”), in place of its label.
  • Timeout: after ACTION_TIMEOUT_MS (10 s), the action stops waiting. The banner shows the timeout message and every button is enabled again. The request itself is not cancelled; if it finishes later, the store applies its result as usual.
  • Errors are visible. Every store error (apiError) and every action failure shows in one banner at the top of the screen, above overlays.

C. busy.tsx

import React, { createContext, useCallback, useContext, useMemo, useState } from 'react';

export interface BusyContextValue {
  busy: boolean;
  begin: () => void;
  end: () => void;
}

const noop = () => {};
/** Default: never busy, so components work without the provider (tests, isolated renders). */
export const BusyContext = createContext<BusyContextValue>({ busy: false, begin: noop, end: noop });

export function nextBusyCount(count: number, change: 'begin' | 'end'): number {
  return change === 'begin' ? count + 1 : Math.max(0, count - 1);
}

export function BusyProvider({ children }: { children: React.ReactNode }) {
  const [count, setCount] = useState(0);
  const begin = useCallback(() => setCount(c => nextBusyCount(c, 'begin')), []);
  const end = useCallback(() => setCount(c => nextBusyCount(c, 'end')), []);
  const value = useMemo(() => ({ busy: count > 0, begin, end }), [count, begin, end]);
  return <BusyContext.Provider value={value}>{children}</BusyContext.Provider>;
}

export function useGlobalBusy(): BusyContextValue {
  return useContext(BusyContext);
}

D. feedback.tsx

import React, { createContext, useCallback, useContext, useMemo, useState } from 'react';
import { AlertTriangle, X } from 'lucide-react';
import { IconButton } from './IconButton';

interface FeedbackContextValue {
  showError: (message: string) => void;
  dismiss: () => void;
}

const FeedbackContext = createContext<FeedbackContextValue | null>(null);

export function FeedbackProvider({ children }: { children: React.ReactNode }) {
  const [message, setMessage] = useState<string | null>(null);
  const showError = useCallback((m: string) => setMessage(m), []);
  const dismiss = useCallback(() => setMessage(null), []);
  const value = useMemo(() => ({ showError, dismiss }), [showError, dismiss]);
  return (
    <FeedbackContext.Provider value={value}>
      <FeedbackBanner message={message} onDismiss={dismiss} />
      {children}
    </FeedbackContext.Provider>
  );
}

/** Falls back to console.error outside the provider so isolated renders and tests never crash. */
export function useFeedback(): FeedbackContextValue {
  const ctx = useContext(FeedbackContext);
  return ctx ?? { showError: (m: string) => console.error('[feedback]', m), dismiss: () => {} };
}

export function FeedbackBanner({ message, onDismiss }: { message: string | null; onDismiss: () => void }) {
  if (!message) return null;
  return (
    <div
      role="alert"
      data-testid="feedback-banner"
      className="fixed inset-x-0 top-0 z-2000 flex items-start justify-between gap-3 bg-red-600 px-4 py-3 text-sm font-semibold text-white shadow-md sm:px-5"
    >
      <div className="flex min-w-0 items-start gap-2">
        <AlertTriangle size={18} className="mt-px shrink-0" aria-hidden="true" />
        <span className="break-words">{message}</span>
      </div>
      <IconButton aria-label="Dismiss error" ignoreBusy onClick={onDismiss} className="min-h-11 min-w-11 text-white enabled:hover:bg-white/10 enabled:hover:text-white">
        <X size={18} />
      </IconButton>
    </div>
  );
}

The banner is above overlays (Overlay uses z-1000), so it is visible over an open drawer. It stays until dismissed or replaced by the next error.

E. useAction.ts

import { useCallback, useEffect, useRef, useState } from 'react';
import { useGlobalBusy } from './busy';
import { useFeedback } from './feedback';
import { ACTION_FAILED_MESSAGE, ACTION_TIMEOUT_MESSAGE, ACTION_TIMEOUT_MS } from './actionConfig';

export class ActionTimeoutError extends Error {
  constructor() {
    super(ACTION_TIMEOUT_MESSAGE);
    this.name = 'ActionTimeoutError';
  }
}

export function raceWithTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  return new Promise<T>((resolve, reject) => {
    const timer = setTimeout(() => reject(new ActionTimeoutError()), ms);
    promise.then(
      v => { clearTimeout(timer); resolve(v); },
      e => { clearTimeout(timer); reject(e); }
    );
  });
}

export function actionErrorMessage(err: unknown): string {
  if (err instanceof ActionTimeoutError) return ACTION_TIMEOUT_MESSAGE;
  if (err instanceof Error && err.message) return err.message;
  return ACTION_FAILED_MESSAGE;
}

/** The framework-free core of useAction, exported for tests. Returns undefined on failure or timeout. */
export async function executeAction<R>(
  fn: () => Promise<R> | R,
  deps: { begin: () => void; end: () => void; showError: (m: string) => void; timeoutMs?: number }
): Promise<R | undefined> {
  deps.begin();
  try {
    return await raceWithTimeout(Promise.resolve().then(fn), deps.timeoutMs ?? ACTION_TIMEOUT_MS);
  } catch (err) {
    deps.showError(actionErrorMessage(err));
    return undefined;
  } finally {
    deps.end();
  }
}

/**
 * Wraps a click handler: sets `busy` for the button's loading state, holds the global busy lock,
 * enforces the timeout and shows failures in the banner. A second run while busy is ignored.
 * Handlers that want to handle an error themselves (for example the match conflict notice)
 * catch it inside fn and do not rethrow.
 */
export function useAction<A extends unknown[], R>(fn: (...args: A) => Promise<R> | R) {
  const { begin, end } = useGlobalBusy();
  const { showError } = useFeedback();
  const [busy, setBusy] = useState(false);
  const runningRef = useRef(false);
  const mountedRef = useRef(true);
  const fnRef = useRef(fn);
  fnRef.current = fn;
  useEffect(() => () => { mountedRef.current = false; }, []);

  const run = useCallback(async (...args: A): Promise<R | undefined> => {
    if (runningRef.current) return undefined;
    runningRef.current = true;
    setBusy(true);
    try {
      return await executeAction(() => fnRef.current(...args), { begin, end, showError });
    } finally {
      runningRef.current = false;
      if (mountedRef.current) setBusy(false);
    }
  }, [begin, end, showError]);

  return { run, busy };
}

J. Tests: src/components/__tests__/busyFoundation.test.tsx

Use renderToStaticMarkup (as directorySections.test.tsx does) and vi.useFakeTimers() where noted. The repo has no DOM test library; do not add one.

  1. raceWithTimeout: resolves with the value; rejects with the promise's error; with fake timers, a never-settling promise rejects with ActionTimeoutError after ACTION_TIMEOUT_MS.
  2. executeAction: success returns the value and calls begin then end once each and no showError; a thrown Error('boom') returns undefined, calls showError('boom') and still calls end; a thrown non-Error shows ACTION_FAILED_MESSAGE; a timeout (fake timers, timeoutMs: 50) shows ACTION_TIMEOUT_MESSAGE and calls end.
  3. nextBusyCount: begin increments; end decrements; end at 0 stays 0.
  4. <Button loading loadingText="Saving…">Save</Button> renders button-spinner, “Saving…”, not “Save”, a disabled attribute and aria-busy="true".
  5. Inside <BusyContext.Provider value={{ busy: true, begin() {}, end() {} }}>: a plain Button renders disabled; a Button ignoreBusy does not; an IconButton renders disabled. Outside any provider, a plain Button is enabled.
  6. FeedbackBanner with a message renders role="alert" and the message; with null renders nothing.
  7. ConfirmDialog still renders its title and buttons with a synchronous onConfirm (static render, open).

Specs / Event readiness / ER.6

Step ER.6: Live updates in every open tab

After every successful tournament write the API notifies the realtime worker; every open page for that tournament gets the message and re-fetches, with no manual refresh. Anonymous re-fetches go through Vercel's CDN, so 1,000 viewers cost one database read per change, not 1,000. The qual timer also uses the server's clock.

Executor: any model. Prerequisites: ER.3 (revision and locked writes), ER.5 (code present; deployment is not needed for this step's tests), and ER.7 if it is running at the same time (both edit src/App.tsx and store.tsx; run them one after the other, ER.7 first). Read first: index.html “Rules for every executor”, docs/TESTING_STRATEGY.md.

How it fits together

  1. A judge saves a score. The locked write commits with revision N (ER.3).
  2. The API calls the worker: POST {REALTIME_URL}/t/{tournamentId}/publish with { revision: N }, after the response is sent (waitUntil), so the judge never waits on it.
  3. Every viewer socket for that tournament receives { type: 'changed', tournamentId, revision: N }.
  4. Each tab ignores it if it already has revision ≥ N; otherwise it calls refreshTournament. Anonymous tabs wait a random 0–1.5 s first and fetch /api/tournaments/{id}?v=N, which the CDN caches per N; signed-in tabs fetch immediately with no cache.

A. Server publish: src/server/realtime.ts (new)

import { waitUntil } from '@vercel/functions';

/**
 * Tells the realtime worker that a tournament changed. Fire-and-forget: never throws, never delays
 * the response. Does nothing when REALTIME_URL or REALTIME_PUBLISH_SECRET is unset (local dev, tests).
 */
export function publishTournamentChanged(tournamentId: string, revision: number): void {
  const base = process.env.REALTIME_URL;
  const secret = process.env.REALTIME_PUBLISH_SECRET;
  if (!base || !secret || process.env.VITEST) return;
  const url = `${base.replace(/\/+$/, '')}/t/${encodeURIComponent(tournamentId)}/publish`;
  const task = fetch(url, {
    method: 'POST',
    headers: { Authorization: `Bearer ${secret}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ revision }),
    signal: AbortSignal.timeout(3000),
  }).then(
    r => { if (!r.ok) console.warn(`[realtime] publish ${tournamentId} -> ${r.status}`); },
    err => console.warn(`[realtime] publish ${tournamentId} failed:`, err?.message || err)
  );
  try {
    waitUntil(task);
  } catch {
    // Not on Vercel (Vite dev server): the promise still runs in the long-lived process.
  }
}

@vercel/functions is installed by ER.2. Outside Vercel, waitUntil either does nothing or throws; the promise runs either way.

C. Server clock on the client: src/utils/serverClock.ts (new)

let offsetMs = 0;

/** Records the server's clock from a response header. Ignores missing or invalid values. */
export function recordServerTime(headerValue: string | null, receivedAtMs: number = Date.now()): void {
  const server = Number(headerValue);
  if (!headerValue || !Number.isFinite(server) || server <= 0) return;
  offsetMs = server - receivedAtMs;
}

/** The current time on the server's clock (falls back to the device clock until a response arrives). */
export function serverNow(): number {
  return Date.now() + offsetMs;
}

/** Test helper. */
export function resetServerClock(): void {
  offsetMs = 0;
}

In store.tsx apiCall, right after const res = await fetch(...), add if (!endpoint.includes('?v=') && !endpoint.includes('&v=')) recordServerTime(res.headers.get('X-Server-Time')); (a CDN-cached response carries an old time). Guard with res.headers?.get if test mocks return a response without headers.

In qualTimer.ts, import serverNow from '../../utils/serverClock' and replace every Date.now() in the file with serverNow(), including the default parameter of getQualTimerRemainingSeconds. Every viewer and the admin who starts the timer then count from the same clock.

E. Pure scheduling helpers: src/features/tournament/live/liveScheduler.ts (new)

export const RECONNECT_STEPS_MS = [1000, 2000, 4000, 8000, 16000, 30000];
export const PING_INTERVAL_MS = 25_000;
export const PONG_TIMEOUT_MS = 10_000;
export const HIDDEN_DISCONNECT_MS = 60_000;
export const ANON_REFRESH_JITTER_MS = 1500;

/** Delay before reconnect attempt `attempt` (0-based), ±20% jitter. `random` is injectable for tests. */
export function reconnectDelayMs(attempt: number, random: () => number = Math.random): number {
  const base = RECONNECT_STEPS_MS[Math.min(Math.max(attempt, 0), RECONNECT_STEPS_MS.length - 1)];
  return Math.round(base * (0.8 + random() * 0.4));
}

/** Spreads anonymous refreshes so 1,000 viewers do not hit the CDN in the same millisecond. */
export function refreshJitterMs(isAuthenticated: boolean, random: () => number = Math.random): number {
  return isAuthenticated ? 0 : Math.floor(random() * ANON_REFRESH_JITTER_MS);
}

/** True when the tab already has this revision or newer. */
export function isStaleEvent(eventRevision: number, knownRevision: number | undefined): boolean {
  return typeof knownRevision === 'number' && eventRevision <= knownRevision;
}

/** https://x → wss://x/t/{id}/ws; http://x → ws://x/t/{id}/ws. */
export function toWebSocketUrl(baseUrl: string, tournamentId: string): string {
  const trimmed = baseUrl.replace(/\/+$/, '');
  const wsBase = trimmed.replace(/^https:/, 'wss:').replace(/^http:/, 'ws:');
  return `${wsBase}/t/${encodeURIComponent(tournamentId)}/ws`;
}

export interface LiveMessage { type: 'changed'; tournamentId: string; revision: number }

export function parseLiveMessage(data: unknown): LiveMessage | null {
  if (typeof data !== 'string' || data === 'pong') return null;
  try {
    const m = JSON.parse(data);
    if (m && m.type === 'changed' && typeof m.tournamentId === 'string' && typeof m.revision === 'number') return m;
  } catch {
    // ignore
  }
  return null;
}

F. The hook: src/features/tournament/live/useTournamentLive.ts (new)

Signature: export function useTournamentLive(tournamentId: string | null | undefined): void. It reads tournaments and refreshTournament from useTournament() and getAuthToken from '../../auth/AuthContext'. Behavior, all inside one useEffect keyed on [tournamentId]:

  1. Do nothing if !tournamentId, !REALTIME_URL, or typeof WebSocket === 'undefined'.
  2. Keep the latest known revision in a ref, updated by a separate effect: knownRevisionRef.current = tournaments.find(t => t.id === tournamentId)?.revision. Keep refreshTournament in a ref too, so the main effect does not reconnect when it changes.
  3. connect(): new WebSocket(toWebSocketUrl(REALTIME_URL, tournamentId)). On open: reset the attempt counter to 0; start an interval every PING_INTERVAL_MS that sends 'ping' and starts a PONG_TIMEOUT_MS timer which calls ws.close(); if this is a reconnect (not the first open), call scheduleRefresh(undefined) once to catch up on anything missed.
  4. On message: if event.data === 'pong', clear the pong timer. Otherwise parseLiveMessage; ignore null, a different tournamentId, or isStaleEvent(m.revision, knownRevisionRef.current); else scheduleRefresh(m.revision).
  5. scheduleRefresh(revision) coalesces: keep pendingRevision (the highest seen) and one timer. If a timer is already set, only raise pendingRevision. Otherwise set a timer for refreshJitterMs(Boolean(getAuthToken())) ms that calls refreshRef.current(tournamentId, { revision: pendingRevision }), then clears both. If a refresh is already in flight when the timer fires, wait for it and then refresh once more only if pendingRevision is above knownRevisionRef.current.
  6. On close or error: clear ping and pong timers; unless the effect was cleaned up or the tab is hidden, schedule connect() after reconnectDelayMs(attempt++).
  7. Hidden tabs: on visibilitychange to hidden, start a HIDDEN_DISCONNECT_MS timer that closes the socket (counts as cleanup: no reconnect). On visible: clear that timer; if the socket is closed, connect() and scheduleRefresh(undefined).
  8. Cleanup: mark cleaned up, clear every timer, remove the listener, ws.close(1000).

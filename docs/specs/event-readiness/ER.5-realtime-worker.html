Step ER.5: Cloudflare realtime worker

A small Cloudflare Worker with one Durable Object per tournament. Browsers hold a WebSocket to it; the API tells it “tournament X changed, revision N”, and it forwards that one tiny message to every open socket. On event days, a cron job also keeps the Vercel function and Neon awake.

Executor: any model. Prerequisite: none; it can run in parallel with any other ER step (it touches no file under src/). Read first: index.html “Rules for every executor”. The deploy at the end needs the user (see section F).

Design

  • Messages carry no data. The worker only says {"type":"changed","tournamentId":"…","revision":N}. Clients then fetch the tournament from the API as they do today, so permissions and redaction stay in one place.
  • Hibernation WebSockets (ctx.acceptWebSocket, setWebSocketAutoResponse): idle sockets cost no compute time, and the client's ping is answered by Cloudflare without waking the object.
  • Free-tier budget (100,000 requests per day; each WebSocket connect is a request, and incoming WebSocket messages are billed as 1/20 of a request): 1,000 viewers connecting once and pinging every 25 seconds for 8 hours is about 1,000 + 1,000 × 1,152 / 20 ≈ 58,600. Pings answered by the auto-response do not wake the object. Broadcasts are outgoing messages and are not billed as requests.

D. realtime/src/policy.ts (pure, no Cloudflare imports)

/** Origins allowed to open a socket. Vercel preview URLs are allowed when allowVercelPreviews is true. */
export function isAllowedOrigin(origin: string | null, allowedCsv: string, allowVercelPreviews: boolean): boolean {
  if (!origin) return false;
  const allowed = allowedCsv.split(',').map(s => s.trim()).filter(Boolean);
  if (allowed.includes(origin)) return true;
  if (allowVercelPreviews) {
    try {
      const url = new URL(origin);
      return url.protocol === 'https:' && url.hostname.endsWith('.vercel.app');
    } catch {
      return false;
    }
  }
  return false;
}

/** True when `now` falls on or between the inclusive UTC dates (YYYY-MM-DD). Empty or invalid dates mean false. */
export function shouldKeepWarm(now: Date, fromDate: string, untilDate: string): boolean {
  const re = /^\d{4}-\d{2}-\d{2}$/;
  if (!re.test(fromDate) || !re.test(untilDate)) return false;
  const today = now.toISOString().slice(0, 10);
  return today >= fromDate && today <= untilDate;
}

export type Route =
  | { kind: 'ws'; tournamentId: string }
  | { kind: 'publish'; tournamentId: string }
  | { kind: 'health' }
  | { kind: 'notFound' };

const ID_RE = /^[A-Za-z0-9_-]{1,64}$/;

export function parseRoute(pathname: string): Route {
  if (pathname === '/health') return { kind: 'health' };
  const m = pathname.match(/^\/t\/([^/]+)\/(ws|publish)$/);
  if (!m || !ID_RE.test(m[1])) return { kind: 'notFound' };
  return m[2] === 'ws' ? { kind: 'ws', tournamentId: m[1] } : { kind: 'publish', tournamentId: m[1] };
}

/** Constant-time string compare for the publish secret. */
export function safeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}

E. realtime/src/index.ts

import { DurableObject } from 'cloudflare:workers';
import { isAllowedOrigin, parseRoute, safeEqual, shouldKeepWarm } from './policy';

export interface Env {
  CHANNELS: DurableObjectNamespace<TournamentChannel>;
  ALLOWED_ORIGINS: string;
  ALLOW_VERCEL_PREVIEWS: string;
  KEEP_WARM_URL: string;
  KEEP_WARM_FROM: string;
  KEEP_WARM_UNTIL: string;
  PUBLISH_SECRET: string;
}

/** One instance per tournament id. Holds that tournament's viewer sockets. */
export class TournamentChannel extends DurableObject<Env> {
  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    // Answered by Cloudflare without waking the object.
    ctx.setWebSocketAutoResponse(new WebSocketRequestResponsePair('ping', 'pong'));
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url);
    if (url.pathname === '/connect') {
      const pair = new WebSocketPair();
      const [client, server] = Object.values(pair);
      this.ctx.acceptWebSocket(server);
      return new Response(null, { status: 101, webSocket: client });
    }
    if (url.pathname === '/broadcast') {
      const message = await request.text();
      let sent = 0;
      for (const ws of this.ctx.getWebSockets()) {
        try {
          ws.send(message);
          sent++;
        } catch {
          // Socket already closing; Cloudflare removes it.
        }
      }
      return Response.json({ sent });
    }
    return new Response('Not found', { status: 404 });
  }

  async webSocketMessage(): Promise<void> {
    // Clients send only "ping", which the auto-response handles. Ignore anything else.
  }

  async webSocketClose(ws: WebSocket, code: number): Promise<void> {
    try {
      ws.close(code === 1005 ? 1000 : code, 'closing');
    } catch {
      // already closed
    }
  }
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    const route = parseRoute(url.pathname);

    if (route.kind === 'health') return Response.json({ status: 'ok' });
    if (route.kind === 'notFound') return new Response('Not found', { status: 404 });

    const stub = env.CHANNELS.get(env.CHANNELS.idFromName(route.tournamentId));

    if (route.kind === 'ws') {
      if (request.headers.get('Upgrade')?.toLowerCase() !== 'websocket') {
        return new Response('Expected WebSocket', { status: 426 });
      }
      const origin = request.headers.get('Origin');
      if (!isAllowedOrigin(origin, env.ALLOWED_ORIGINS, env.ALLOW_VERCEL_PREVIEWS === 'true')) {
        return new Response('Origin not allowed', { status: 403 });
      }
      return stub.fetch(new Request('https://do/connect', request));
    }

    // publish
    if (request.method !== 'POST') return new Response('Method not allowed', { status: 405 });
    const auth = request.headers.get('Authorization') || '';
    const token = auth.startsWith('Bearer ') ? auth.slice(7) : '';
    if (!env.PUBLISH_SECRET || !safeEqual(token, env.PUBLISH_SECRET)) {
      return new Response('Unauthorized', { status: 401 });
    }
    let revision = 0;
    try {
      const body = (await request.json()) as { revision?: unknown };
      revision = typeof body.revision === 'number' ? body.revision : 0;
    } catch {
      return new Response('Bad JSON', { status: 400 });
    }
    const message = JSON.stringify({ type: 'changed', tournamentId: route.tournamentId, revision });
    return stub.fetch('https://do/broadcast', { method: 'POST', body: message });
  },

  async scheduled(_event: ScheduledController, env: Env, ctx: ExecutionContext): Promise<void> {
    if (!shouldKeepWarm(new Date(), env.KEEP_WARM_FROM, env.KEEP_WARM_UNTIL)) return;
    ctx.waitUntil(fetch(env.KEEP_WARM_URL, { headers: { 'User-Agent': 'matchfoundry-keepwarm' } }).then(() => undefined, () => undefined));
  },
} satisfies ExportedHandler<Env>;

If npm run realtime:typecheck reports that a type name above differs in the installed @cloudflare/workers-types (for example ScheduledController), use the name the package exports and record the change in the report. Do not change behavior.

Why the keep-warm hits /api/health: it runs SELECT 1, so one request every 4 minutes keeps a Vercel function instance warm and stops Neon's 5-minute scale-to-zero. Outside the configured dates it does nothing, so Neon's free compute hours are not spent on quiet weeks.

F. Tests: realtime/src/policy.test.ts

Vitest's default include already picks up this file; it imports only ./policy.

  1. isAllowedOrigin: a listed origin → true; null → false; https://evil.example → false; https://matchfoundry-git-x.vercel.app → true with previews on, false with previews off; http://foo.vercel.app → false; https://vercel.app.evil.example → false.
  2. shouldKeepWarm: inside the range, on both boundary dates → true; the day before and after → false; empty strings → false; "2026-13-40x" → false.
  3. parseRoute: /health; /t/abc-123/ws; /t/abc-123/publish; /t/abc/other, /t/../ws, /t/a%20b/ws, / → notFound.
  4. safeEqual: equal → true; different same-length → false; different length → false.

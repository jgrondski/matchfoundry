Step ER.12: Keep the API warm on event days, from tournament dates

The realtime worker's keep-warm cron stops reading two hand-edited dates in wrangler.toml. Once a day it asks the API for upcoming event days and stores the answer in a Durable Object; every 4 minutes it pings /api/health only when today falls inside one of those windows.

Executor: any model. Prerequisite: ER.11 (the start_date and end_date columns). Shared files: src/server/api.ts (one new route). Do not run alongside ER.6. Read first: index.html “Rules for every executor”, docs/TESTING_STRATEGY.md.

Why

ER.5's cron pings /api/health every 4 minutes between KEEP_WARM_FROM and KEEP_WARM_UNTIL. That keeps the Vercel function and the Neon database awake on event days (a cold start costs about 2.5 s). The two dates are edited by hand in wrangler.toml and need a manual redeploy, which is easy to forget.

The worker cannot read the database directly, and asking the API every 4 minutes would wake the database all year, which is exactly what the date range avoids. So it asks once a day and remembers the answer. A failed fetch keeps the previous answer and retries an hour later. Each check sends at most one request to the API.

Behavior after this step

  • GET /api/keep-warm-schedule (public, Cache-Control: no-store) returns { "windows": [{ "from": "YYYY-MM-DD", "until": "YYYY-MM-DD" }] }. There is one window per non-test tournament with a start date that lasts at most 4 days, running from its first day to one day after its last (a US venue's last evening is already the next day in UTC). Longer events, such as month-long online tournaments, are left out so the database is not kept awake for weeks. Windows that have ended are left out. Windows are sorted by from.
  • The worker refreshes that schedule at most once every 24 hours (and at most once an hour after a failure), and pings /api/health every 4 minutes while today (UTC) is inside any window.
  • GET https://<worker>/keep-warm returns the stored schedule (windows, fetchedAt, lastAttemptAt), so anyone can check what the worker will do. It never triggers a fetch.
  • KEEP_WARM_FROM and KEEP_WARM_UNTIL no longer exist.

A. API

  1. Create src/api/keepWarm.ts: 
    import { isNotNull, sql } from 'drizzle-orm';
import { getDb } from '../db';
import { tournaments } from '../db/schema';

/**
 * Days kept warm after an event's last day. Windows are UTC dates, and a US venue's evening is
 * already the next day in UTC (6 pm Pacific is 2 am UTC), so the last evening needs one more day.
 */
export const KEEP_WARM_DAYS_AFTER = 1;

/**
 * Longest event (in days, inclusive) that is kept warm. Longer events, such as month-long online
 * tournaments, are left out: warming them would keep the database awake for weeks.
 */
export const KEEP_WARM_MAX_EVENT_DAYS = 4;

export interface KeepWarmWindow {
  from: string;
  until: string;
}

interface EventDays {
  startDate: string | null;
  endDate: string | null;
  isTest: boolean;
}

/** Shifts a YYYY-MM-DD date by whole days. */
export function addDays(isoDate: string, days: number): string {
  const d = new Date(`${isoDate}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + days);
  return d.toISOString().slice(0, 10);
}

/** Days from start to end, both included (a one-day event is 1). */
export function eventLengthDays(startDate: string, endDate: string): number {
  const ms = Date.parse(`${endDate}T00:00:00Z`) - Date.parse(`${startDate}T00:00:00Z`);
  return Math.round(ms / 86_400_000) + 1;
}

/**
 * One window per non-test event with a start date that lasts at most KEEP_WARM_MAX_EVENT_DAYS,
 * from its first day to KEEP_WARM_DAYS_AFTER past its last, keeping only windows that end today
 * (UTC) or later, sorted by start.
 */
export function buildKeepWarmWindows(events: EventDays[], today: string): KeepWarmWindow[] {
  return events
    .filter((e): e is EventDays & { startDate: string } => !e.isTest && Boolean(e.startDate))
    .filter(e => eventLengthDays(e.startDate, e.endDate || e.startDate) <= KEEP_WARM_MAX_EVENT_DAYS)
    .map(e => ({
      from: e.startDate,
      until: addDays(e.endDate || e.startDate, KEEP_WARM_DAYS_AFTER),
    }))
    .filter(w => w.until >= today)
    .sort((a, b) => a.from.localeCompare(b.from));
}

/** The schedule the realtime worker fetches once a day (GET /api/keep-warm-schedule). */
export async function getKeepWarmWindows(now: Date = new Date()): Promise<KeepWarmWindow[]> {
  const rows = await getDb()
    .select({
      startDate: tournaments.startDate,
      endDate: tournaments.endDate,
      isTest: sql<boolean | null>`${tournaments.metadata} -> 'isTest'`,
    })
    .from(tournaments)
    .where(isNotNull(tournaments.startDate));
  return buildKeepWarmWindows(
    rows.map(r => ({ startDate: r.startDate, endDate: r.endDate, isTest: Boolean(r.isTest) })),
    now.toISOString().slice(0, 10)
  );
}

B. Worker policy (realtime/src/policy.ts)

Delete shouldKeepWarm. Add:

export interface KeepWarmWindow {
  from: string;
  until: string;
}

export interface StoredSchedule {
  windows: KeepWarmWindow[];
  /** When the last successful fetch happened (ms since epoch), or null if never. */
  fetchedAt: number | null;
  /** When the last fetch was attempted, successful or not (ms since epoch), or null if never. */
  lastAttemptAt: number | null;
}

export const EMPTY_SCHEDULE: StoredSchedule = { windows: [], fetchedAt: null, lastAttemptAt: null };
export const SCHEDULE_REFRESH_MS = 24 * 60 * 60 * 1000;
export const SCHEDULE_RETRY_MS = 60 * 60 * 1000;

const ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

/** True when today's UTC date is inside any window, boundaries included. */
export function isInKeepWarmWindow(now: Date, windows: KeepWarmWindow[]): boolean {
  const today = now.toISOString().slice(0, 10);
  return windows.some(w => today >= w.from && today <= w.until);
}

/** The windows from a /api/keep-warm-schedule body, or null when the body is not in that shape. */
export function parseKeepWarmSchedule(body: unknown): KeepWarmWindow[] | null {
  if (!body || typeof body !== 'object' || !Array.isArray((body as { windows?: unknown }).windows)) return null;
  const windows: KeepWarmWindow[] = [];
  for (const w of (body as { windows: unknown[] }).windows) {
    if (!w || typeof w !== 'object') return null;
    const { from, until } = w as { from?: unknown; until?: unknown };
    if (typeof from !== 'string' || typeof until !== 'string' || !ISO_DATE.test(from) || !ISO_DATE.test(until)) return null;
    windows.push({ from, until });
  }
  return windows;
}

/** True when the stored schedule should be fetched again: never fetched or a day old, and no attempt in the last hour. */
export function isScheduleDue(now: number, schedule: StoredSchedule): boolean {
  const stale = schedule.fetchedAt === null || now - schedule.fetchedAt >= SCHEDULE_REFRESH_MS;
  const recentlyTried = schedule.lastAttemptAt !== null && now - schedule.lastAttemptAt < SCHEDULE_RETRY_MS;
  return stale && !recentlyTried;
}

    const KEEP_WARM_HEADERS = { 'User-Agent': 'matchfoundry-keepwarm' };

/** Single instance ("schedule") that stores the keep-warm windows fetched from the API. */
export class KeepWarmSchedule extends DurableObject<Env> {
  async status(): Promise<StoredSchedule> {
    return (await this.ctx.storage.get<StoredSchedule>('schedule')) ?? EMPTY_SCHEDULE;
  }

  /** Called by the cron every 4 minutes: refresh the schedule when due, then ping the API inside a window. */
  async tick(): Promise<void> {
    const now = Date.now();
    let schedule = await this.status();
    if (isScheduleDue(now, schedule)) {
      schedule = { ...schedule, lastAttemptAt: now };
      try {
        const res = await fetch(this.env.KEEP_WARM_SCHEDULE_URL, { headers: KEEP_WARM_HEADERS });
        const windows = res.ok ? parseKeepWarmSchedule(await res.json()) : null;
        if (windows) schedule = { windows, fetchedAt: now, lastAttemptAt: now };
      } catch {
        // Keep the previous windows; isScheduleDue retries after SCHEDULE_RETRY_MS.
      }
      await this.ctx.storage.put('schedule', schedule);
    }
    if (isInKeepWarmWindow(new Date(now), schedule.windows)) {
      await fetch(this.env.KEEP_WARM_URL, { headers: KEEP_WARM_HEADERS }).catch(() => undefined);
    }
  }
}
